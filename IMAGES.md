## Tips
- Use JPG or WebP, quality around 80, and keep each file under 300 KB.
- Sizes above are the recommended size (about 2x the displayed size for sharp screens). Larger images work but slow the page down.
- Images are cropped to fill their frame (`object-fit: cover`), so keep the subject near the center.
- To use a different file name or format, edit the `src` in the HTML.
- Write a short, descriptive `alt` text for every image you replace.
- Use `og-cover.jpg` at 1200 x 630 and make the `og:image` URL absolute (see "SEO" in `CUSTOMIZATION.md`).
